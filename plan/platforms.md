# Showcase Platforms & Registries

A list of places to submit and showcase your MCP servers to the community.

## Primary Registries

| Platform                  | URL                                                                                          | Method                                    |
| ------------------------- | -------------------------------------------------------------------------------------------- | ----------------------------------------- |
| **MCP Official Registry** | [github.com/modelcontextprotocol/registry](https://github.com/modelcontextprotocol/registry) | PR to `registry.json`                     |
| **Smithery**              | [smithery.ai](https://smithery.ai/)                                                          | Automatic via GitHub App or Manual Submit |
| **Glama**                 | [glama.ai/mcp](https://glama.ai/mcp)                                                         | Web submission form                       |
| **Pulse**                 | [pulse.build](https://pulse.build/)                                                          | Community submission                      |
| **Mozilla AI Registry**   | [github.com/mozilla-ai/mcp-registry](https://github.com/mozilla-ai/mcp-registry)             | Open Source Community Registry            |

## Community Curated Lists (GitHub)

- **Awesome MCP Servers**: [mctrinh/awesome-mcp-servers](https://github.com/mctrinh/awesome-mcp-servers)
- **MCP Servers Official List**: [modelcontextprotocol/servers](https://github.com/modelcontextprotocol/servers) (Usually for official/high-quality examples)

## Submission Checklist (per MCP)

A checklist system to be integrated into the showcase app:

- [ ] [ ] Build & Publish to NPM / PyPI
- [ ] [ ] Create GitHub Repository with clear README
- [ ] [ ] Add to Smithery.ai
- [ ] [ ] Add to Glama.ai
- [ ] [ ] PR to Official MCP Registry
- [ ] [ ] Share on Twitter/Bluesky with `#MCP` hashtag
